# Pion — firma budowlana z Łodzi

Projekt landing page'a. Firma Pion, osoby, adresy, ceny i terminy są fikcyjne.

Otwórz `index.html` w przeglądarce. Nie wymaga instalacji ani budowania.

- `index.html`, `styles.css`, `main.js` — strona
- `assets/` — zdjęcia
- Zdjęcia domów w sekcji „Ostatnie budowy” ładują się z Unsplash, więc potrzebny jest internet. Gdy któreś się nie wczyta, strona pokazuje zamiast niego lokalne zdjęcie z `assets/`.
