# Pion — firma budowlana z Łodzi

Projekt landing page'a do portfolio. Firma Pion, osoby, adresy, ceny i terminy są fikcyjne.

Otwórz `index.html` w przeglądarce. Nie wymaga instalacji ani budowania.

- `index.html`, `styles.css`, `main.js` — strona
- `assets/` — zdjęcia z Wikimedia Commons (licencje CC BY, CC BY-SA, CC0, domena publiczna; autorzy w stopce strony i w `assets/credits.json`)
- `assets/drawings/` — rysunki elewacji i rzutów, generowane przez `node tools/drawings.mjs`
